# TranslateAI

TranslateAI is a professional web-based language translation chatbot.

## Features

- Professional chatbot interface
- Source language selection
- Target language selection
- Language swapping
- Text translation
- Translation API integration
- Copy translation button
- New chat button
- Character counter
- Responsive design
- Python Flask backend
- HTML/CSS/JavaScript frontend

## Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- MyMemory Translation API

## Supported Languages

- English
- Urdu
- Hindi
- Arabic
- French
- German
- Spanish
- Italian
- Turkish
- Chinese

## Running the Application

Double-click:

start.bat

The application will open in the browser.
